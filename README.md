# Шпаргалка по Stardew Valley

Статический сайт на русском языке для версии 1.6: культуры, рыба, жители, праздники, схема города и календарь с посадками.
Работает без сборки и сервера: обычные HTML, CSS и JavaScript.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `stardew-cheatsheet`.
2. Загрузите в него содержимое этой папки (кнопка **Add file → Upload files**, перетащите все файлы и папки).
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через минуту сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/stardew-cheatsheet/`.

Проверить сайт локально можно, просто открыв `index.html` в браузере.

## Как устроен проект

- `index.html` — страница и навигация.
- `css/style.css` — оформление.
- `js/app.js` — разделы, поиск, календарь, карта.
- `js/data/crops.js` — культуры.
- `js/data/fish.js` — рыба и ловушки.
- `js/data/villagers.js` — жители, праздники и места на карте.

Чтобы исправить или дополнить данные, меняйте только файлы в `js/data/`: каждая запись — одна строка.

## Календарь

- Нажмите на день, чтобы посадить культуру или добавить заметку.
- Для культур считаются повторные сборы и гибель при смене сезона (кроме растений, которым подходит несколько сезонов, и посадок в теплице).
- Записи хранятся в браузере (`localStorage`). Кнопки «Сохранить в файл» и «Загрузить из файла» нужны для переноса между устройствами.
- Ускорение от удобрений и профессии «Земледелец» считается приблизительно.
